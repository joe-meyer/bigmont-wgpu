## Global Constraints

- Limb layout stays 13-bit limbs in `u32`, `LIMB_BITS = 13`. The existing 160-limb behaviour (`LIMBS = 160`, 2,029-bit class) must keep passing every existing test unchanged in meaning.
- Kernels use only WGSL features browsers implement: no `enable f16`, no push constants, no 64-bit integers, no atomics. The browser source differs from native source only by the two prelude lines `enable subgroups;` and `diagnostic(off, subgroup_uniformity);` (naga 30 rejects the first natively).
- Every kernel configuration must pass an oracle comparison before any speed or verdict from it is used. Strict tests: a missing adapter fails the test unless `BIGMONT_ALLOW_SKIP=1`.
- Fermat ladder invariant: `R = 2^(13*limbs) > 16n` for every modulus `n` of the configured bit length (`limbs >= ceil((bits+4)/13)`), because doublings are lazy (values reach `4n` before the next squaring). The plain-squaring contract keeps `R > 4n`.
- Light carry passes at most 20 single-limb steps apart (`PERIOD = 20`; safe limit 24 for 32-bit accumulators).
- File contract (Beacon `cuda/g1_fermat_v3.cu`): candidates `u32 magic 'G2C1' (0x31433247) | u32 bits | u64 count | count * (bits/32) u32 limbs, little-endian limb order`; verdicts `u32 magic 'G2V1' (0x31563247) | u32 bits | u64 count | count bytes`, 0 = composite, 1 = Fermat-2 PRP, 2 = GEC alarm. Verdict files are written to `<path>.tmp` then renamed. `bits` is the container width; actual numbers are shorter (about 2,029 bits in a 2,048 container). All candidates are odd.
- No Gerbicz check in Phase 1 (Beacon's kit defaults `FERMAT_GEC` to 0); verdict 2 is never produced. Integrity comes from the canary, CPU re-verification of every GPU PRP verdict, and sampled CPU re-verification of composites.

```rust
/// Limbs needed so that R = 2^(13*limbs) exceeds 16n for every n below 2^bits. The Fermat ladder
/// doubles lazily (no reduction), so values reach 4n before the next squaring, which needs R > 16n.
pub fn limbs_for_bits(bits: u32) -> usize {
    (bits + 4).div_ceil(LIMB_BITS) as usize
}

/// Split x into `limbs` limbs of 13 bits (little-endian), one per u32.
pub fn pack_limbs_n(x: &BigUint, limbs: usize) -> Vec<u32> {
    assert!(x.bits() <= u64::from(LIMB_BITS) * limbs as u64, "value does not fit in {limbs} limbs");
    let d = x.to_u32_digits();
    (0..limbs)
        .map(|k| {
            let o = LIMB_BITS as usize * k;
            let (w, s) = (o / 32, o % 32);
            let lo = u64::from(d.get(w).copied().unwrap_or(0));
            let hi = u64::from(d.get(w + 1).copied().unwrap_or(0));
            (((lo | (hi << 32)) >> s) as u32) & LIMB_MASK
        })
        .collect()
}

pub fn pack_limbs(x: &BigUint) -> Vec<u32> {
    pack_limbs_n(x, LIMBS)
}

/// x <- x^2 * R^-1 mod n, `squarings` times, with R = 2^(13*limbs). `n` must be odd. The result is in
/// [0, n); with `squarings == 0` it is `x0 % n`.
pub fn mont_square_chain_n(n: &BigUint, x0: &BigUint, squarings: u32, limbs: usize) -> BigUint {
    assert!(n.bit(0), "modulus must be odd");
    let r_bits = LIMB_BITS * limbs as u32;
    let mask = (BigUint::one() << r_bits) - 1u32;
    let ninv = inv_mod_pow2(n, r_bits);
    let mut x = x0 % n;
    for _ in 0..squarings {
        let x2 = &x * &x;
        let m = ((&mask + 1u32) - ((&x2 * &ninv) & &mask)) & &mask;
        x = ((x2 + m * n) >> r_bits) % n;
    }
    x
}

pub fn mont_square_chain(n: &BigUint, x0: &BigUint, squarings: u32) -> BigUint {
    mont_square_chain_n(n, x0, squarings, LIMBS)
}

/// Base-2 Fermat test: 2^(n-1) = 1 (mod n). True for primes and base-2 pseudoprimes.
pub fn fermat_base2(n: &BigUint) -> bool {
    if n < &BigUint::from(2u32) {
        return false;
    }
    if n == &BigUint::from(2u32) {
        return true;
    }
    if !n.bit(0) {
        return false;
    }
    BigUint::from(2u32).modpow(&(n - 1u32), n).is_one()
}

/// Odd number of exactly `bits` bits that passes `fermat_base2` (small-prime trial filter first).
pub fn random_prp(rng: &mut XorShift64, bits: u32) -> BigUint {
    let small: Vec<u32> = (3u32..1000).filter(|&p| (2..p).take_while(|d| d * d <= p).all(|d| p % d != 0)).collect();
    loop {
        let c = random_odd_modulus(rng, bits);
        if small.iter().any(|&p| (&c % p).is_zero() && c != BigUint::from(p)) {
            continue;
        }
        if fermat_base2(&c) {
            return c;
        }
    }
}
```

```rust
use bigmont_core::gpu::Gpu;

/// Strict by default: a missing adapter or an unsupported configuration fails the test, so a skip
/// cannot masquerade as a pass. `BIGMONT_ALLOW_SKIP=1` turns those cases into loud skips.
/// `BIGMONT_REQUIRE_GPU=1` is accepted for compatibility (if both are set, strict wins).
pub fn skips_allowed() -> bool {
    let is_one = |name: &str| std::env::var(name).is_ok_and(|v| v == "1");
    is_one("BIGMONT_ALLOW_SKIP") && !is_one("BIGMONT_REQUIRE_GPU")
}

pub fn skip(msg: String) {
    if !skips_allowed() {
        panic!("{msg} (set BIGMONT_ALLOW_SKIP=1 to allow skips)");
    }
    eprintln!("SKIP {msg}");
}

/// The selected adapter, or `None` after a loud skip when it cannot run `cfg`.
pub fn open_gpu(cfg: KernelConfig) -> Option<Gpu> {
    let gpu = match Gpu::new() {
        Ok(g) => g,
        Err(e) => {
            skip(format!("{cfg:?}: no adapter: {e}"));
            return None;
        }
    };
    if cfg.needs_subgroups() {
        if let Err(e) = gpu.check_subgroups(cfg.tpi) {
            skip(format!("{cfg:?}: {e}"));
            return None;
        }
    }
    eprintln!("adapter: {} ({:?}), config {cfg:?}", gpu.info.name, gpu.info.backend);
    Some(gpu)
}
```

```rust
/// Where the generated WGSL will run. Browsers require `enable subgroups;`, and Chrome's uniformity
/// analysis cannot prove the loop exits uniform, so the browser prelude also switches that
/// diagnostic off. naga 30 (native wgpu) rejects `enable subgroups;`, so native source has no prelude.
#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum Target {
    Native,
    Browser,
}

impl Target {
    pub(crate) fn prelude(self) -> &'static str {
        match self {
            Target::Native => "",
            Target::Browser => "enable subgroups;\ndiagnostic(off, subgroup_uniformity);\n",
        }
    }
}

#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub struct KernelConfig {
    pub tpi: u32,
    pub wg: u32,
    pub variant: Variant,
    /// Limbs per number (13-bit limbs); a multiple of `tpi`.
    pub limbs: u32,
}

impl KernelConfig {
    /// The Phase 0 size class: 160 limbs (2,029-bit numbers).
    pub const fn new(tpi: u32, wg: u32, variant: Variant) -> Self {
        Self { tpi, wg, variant, limbs: LIMBS as u32 }
    }

    pub const fn with_limbs(mut self, limbs: u32) -> Self {
        self.limbs = limbs;
        self
    }

    /// Config for numbers of `bits` bits that is safe for the Fermat ladder (R > 16n): the smallest
    /// multiple of `tpi` that is at least `limbs_for_bits(bits)`.
    pub fn for_bits(bits: u32, tpi: u32, wg: u32, variant: Variant) -> Self {
        let need = limbs_for_bits(bits) as u32;
        Self::new(tpi, wg, variant).with_limbs(need.div_ceil(tpi) * tpi)
    }

    pub fn validate(&self) -> Result<(), String> {
        if !matches!(self.tpi, 1 | 4 | 8 | 16 | 32) {
            return Err(format!("tpi {} not supported (1, 4, 8, 16, 32)", self.tpi));
        }
        if self.limbs < self.tpi || self.limbs % self.tpi != 0 || self.limbs > 1024 {
            return Err(format!("{} limbs must be a multiple of tpi {} and at most 1024", self.limbs, self.tpi));

        if self.wg == 0 || self.wg % self.tpi != 0 || self.wg > 256 {
            return Err(format!("workgroup size {} must be a multiple of tpi {} and at most 256", self.wg, self.tpi));
        }
        if self.variant == Variant::Unrolled && self.tpi == 1 {
            return Err("the unrolled variant supports tpi 4, 8, 16, 32 only (tpi 1 is rolled-only)".to_string());
        }
        Ok(())
    }

    pub fn limbs_per_lane(&self) -> u32 {
        self.limbs / self.tpi
    }
```

```rust
//! Pure-Rust Montgomery base-2 Fermat test with 64-bit limbs (CIOS), used as the CPU fallback and
//! as an independent check on GPU verdicts. Not constant time. Setup (R mod n) uses num-bigint.

use num_bigint::BigUint;
use num_traits::{One, Zero};

/// Montgomery context for an odd modulus of `w` 64-bit limbs; R = 2^(64 w).
pub struct Mont {
    n: Vec<u64>,
    ninv: u64, // -n^-1 mod 2^64
    w: usize,
}

impl Mont {
    pub fn new(n: &[u64]) -> Mont {
        assert!(n[0] & 1 == 1, "modulus must be odd");
        let mut inv = n[0]; // correct to 3 bits
        for _ in 0..5 {
            inv = inv.wrapping_mul(2u64.wrapping_sub(n[0].wrapping_mul(inv)));
        }
        Mont { n: n.to_vec(), ninv: inv.wrapping_neg(), w: n.len() }
    }

    /// out = a * b * R^-1 mod n for a, b < n. `t` is scratch of length w + 2.
    pub fn mul(&self, a: &[u64], b: &[u64], out: &mut [u64], t: &mut [u64]) {
        let w = self.w;
        t.iter_mut().for_each(|v| *v = 0);
        for i in 0..w {
            let mut c: u128 = 0;
            for j in 0..w {
                let s = u128::from(t[j]) + u128::from(a[j]) * u128::from(b[i]) + c;
                t[j] = s as u64;
                c = s >> 64;
            }
            let s = u128::from(t[w]) + c;
            t[w] = s as u64;
            t[w + 1] = (s >> 64) as u64;
            let m = t[0].wrapping_mul(self.ninv);
            let s = u128::from(t[0]) + u128::from(m) * u128::from(self.n[0]);
            let mut c = s >> 64;
            for j in 1..w {
                let s = u128::from(t[j]) + u128::from(m) * u128::from(self.n[j]) + c;
                t[j - 1] = s as u64;
                c = s >> 64;
            }
            let s = u128::from(t[w]) + c;
            t[w - 1] = s as u64;
            t[w] = t[w + 1] + (s >> 64) as u64;
        }
        out.copy_from_slice(&t[..w]);
        if t[w] != 0 || ge(out, &self.n) {
            sub_in_place(out, &self.n);
        }
    }

    pub fn sqr(&self, a: &[u64], out: &mut [u64], t: &mut [u64]) {
        self.mul(a, a, out, t)
    }

    /// x = 2x mod n for x < n.
    fn double(&self, x: &mut [u64]) {
        let mut carry = 0u64;
        for v in x.iter_mut() {
            let next = *v >> 63;
            *v = (*v << 1) | carry;
            carry = next;
        }
        if carry != 0 || ge(x, &self.n) {
            sub_in_place(x, &self.n);
        }
    }
}

fn ge(a: &[u64], b: &[u64]) -> bool {
    for i in (0..a.len()).rev() {
        if a[i] != b[i] {
            return a[i] > b[i];
        }
    }
    true
}

fn sub_in_place(a: &mut [u64], b: &[u64]) {
    let mut borrow = 0u64;
    for i in 0..a.len() {
        let (d1, b1) = a[i].overflowing_sub(b[i]);
        let (d2, b2) = d1.overflowing_sub(borrow);
        a[i] = d2;
        borrow = u64::from(b1 | b2);
    }
}

fn to_limbs(x: &BigUint, w: usize) -> Vec<u64> {
    let mut v = x.to_u64_digits();
    v.resize(w, 0);
    v
}

/// Base-2 Fermat test: 2^(n-1) = 1 (mod n); same semantics as `bigmont_oracle::fermat_base2`.
pub fn fermat_base2(n: &BigUint) -> bool {
    let two = BigUint::from(2u32);
    if n < &two {
        return false;
    }
    if n == &two {
        return true;
    }
    if !n.bit(0) {
        return false;
    }
    let w = n.to_u64_digits().len();
    let nl = to_limbs(n, w);
    let ctx = Mont::new(&nl);
    let r = (BigUint::one() << (64 * w)) % n; // Montgomery form of 1
    let one_m = to_limbs(&r, w);
    let mut x = to_limbs(&((&r << 1u32) % n), w); // Montgomery form of 2 (top exponent bit)
    let e = n - 1u32;
    let nbits = e.bits();
    let mut t = vec![0u64; w + 2];
    let mut y = vec![0u64; w];
    for i in (0..nbits - 1).rev() {
        ctx.sqr(&x, &mut y, &mut t);
        x.copy_from_slice(&y);
        if e.bit(i) {
            ctx.double(&mut x);
        }
    }
    x == one_m
}

/// Verdicts for every `n`, in order. `threads == 0` uses all cores.
pub fn fermat_batch(ns: &[BigUint], threads: usize) -> Vec<bool> {
    let threads = if threads == 0 { std::thread::available_parallelism().map_or(1, |n| n.get()) } else { threads };
    let threads = threads.min(ns.len()).max(1);
    let per = ns.len().div_ceil(threads).max(1);
    let mut out = vec![false; ns.len()];
    std::thread::scope(|s| {
        for (chunk_in, chunk_out) in ns.chunks(per).zip(out.chunks_mut(per)) {
            s.spawn(move || {
                for (n, o) in chunk_in.iter().zip(chunk_out.iter_mut()) {
                    *o = fermat_base2(n);
                }
            });
        }
    });
    out
}
```

### Task 5: Autotune and per-adapter self-validation (`bigmont-cli::tune`)

**Files:**
- Create: `crates/bigmont-cli/Cargo.toml`, `crates/bigmont-cli/src/lib.rs`, `crates/bigmont-cli/src/tune.rs`, `crates/bigmont-cli/tests/tune.rs`
- Modify: workspace `Cargo.toml` (add `crates/bigmont-cli`)

**Interfaces:**
- Consumes: `bigmont_core::{gpu::{Gpu, Batch, run}, kernel::{KernelConfig, Variant}, runner::Runner}`, `bigmont_cpu::fermat_base2`, oracle.
- Produces in `bigmont_cli::tune`:
  - `pub fn candidates(gpu: &Gpu, bits: u32) -> Vec<KernelConfig>`: unrolled configs for TPI in {4, 8, 16, 32} and wg in {64, 128, 256}, `KernelConfig::for_bits`, keeping those that `validate()` and pass `gpu.check_subgroups(tpi)`. Empty when the adapter has no subgroups.
  - `pub fn self_test(gpu: &Gpu, cfg: KernelConfig, bits: u32) -> Result<(), String>`
  - `pub fn measure(gpu: &Gpu, cfg: KernelConfig) -> Result<f64, String>` returning verified squarings per second
  - `pub struct Tuned { pub cfg: KernelConfig, pub squarings_per_sec: f64, pub from_cache: bool }`
  - `pub fn autotune(gpu: &Gpu, bits: u32, cache: Option<&std::path::Path>, retune: bool) -> Result<Tuned, String>`
  - `Err` when no candidate passes the self-test (the engine then falls back to the CPU).

**Behaviour:**
- `self_test` (a) squaring check: 24 random instances at `13*limbs - 3` bits plus the all-ones modulus, 3 chained squarings through `run`, every instance equal to `mont_square_chain_n`, limbs normalised, value below 2n; (b) Fermat check: build 14 random odd numbers, 3 probable primes (`bigmont_oracle::random_prp` is slow at 2,029 bits, so find them by looping `random_odd_modulus` and testing with `bigmont_cpu::fermat_base2` after a small-prime filter) and the all-ones number, run them through a `Runner` with capacity 8 (two or three chunks), and require every verdict to equal `bigmont_cpu::fermat_base2`; at least one verdict must be `true` and at least one `false`, else `Err("self-test is vacuous")`.
- `measure`: `ipw = cfg.instances_per_workgroup()`; start with `count = ipw * 4`, `squarings = 8`, run once; while the measured time is under 0.05 s and the total work (`count * squarings`) is under the limit (`2^26` for a GPU, `2^18` when `gpu.info.device_type == wgpu::DeviceType::Cpu`), double `squarings`; then take the best of 2 timed runs (`run(..., repeats = 1)` twice, using `Run::best_secs`), verify 4 sampled instances of the last output against the oracle chain (`Err` on mismatch), and return `count * squarings / best_secs`. Groups never exceed 65535.
- `autotune`: cache key line `adapter-name|backend|driver|limbs|variant tpi wg|rate`, one line per key in a plain text file (create parent dir; ignore unreadable cache). Without a cache hit (or with `retune`): for each candidate run `self_test` (log `skip <cfg>: <reason>` to stderr on failure) then `measure`, pick the fastest, write the cache entry. With a cache hit: still run `self_test` for the cached config (cheap); if it fails, retune from scratch.

**Interfaces:**
- Produces:
  - `gpu::AdapterSelector { pub name: Option<String>, pub backend: Option<String>, pub index: Option<usize> }`, `AdapterSelector::from_env()`, `Gpu::open(&AdapterSelector) -> Result<Gpu, String>`; `Gpu::new()` = `open(&from_env())`. `index` counts non-CPU adapters in `enumerate_adapters` order (Beacon's `--device N`).
  - `formats::{CandidateFile { pub bits: u32, pub numbers: Vec<BigUint> }, read_candidates(&Path), write_candidates(&Path, bits, &[BigUint]), read_verdicts(&Path) -> (u32, Vec<u8>), write_verdicts(&Path, bits, &[u8])}`. Reading rejects a wrong magic, a truncated body, or a count that does not match the file length. Writing verdicts goes to `<path>.tmp` then `std::fs::rename`. `numbers` are little-endian `u32` limbs interpreted as one integer.
  - `engine::{Backend { Gpu, Cpu, Auto }, Options { backend, selector, cache: Option<PathBuf>, retune: bool, verify_rate: u32 /* 1 in N composites re-checked on the CPU, 0 = never */, min_gpu_batch: usize /* default 64 */, capacity: u32 /* default 16384 */, threads: usize }, Engine::open(Options) -> Engine, Engine::describe(&self) -> String, Engine::verdicts(&mut self, ns: &[BigUint]) -> Result<Vec<u8>, String>, Engine::report(&self) -> EngineReport }`.
  - Verdict rules: `n < 2` or even and `n != 2` → 0; `n == 2` → 1; everything else from the engine. Never 2.
  - `Engine::verdicts` buckets candidates by exact bit length; per bucket: GPU `Runner` (cached per bit length, built from `tune::autotune` for that length) when the backend is GPU and the bucket has at least `min_gpu_batch` entries, otherwise `bigmont_cpu::fermat_batch`. A GPU error for a bucket falls back to the CPU for that bucket and is counted in the report.
  - Integrity: every GPU PRP verdict (true) is re-run on the CPU; a disagreement uses the CPU verdict, increments `report.prp_disagreements`. One in `verify_rate` GPU composites (every `verify_rate`-th candidate by index) is re-run on the CPU; a disagreement uses the CPU verdict and increments `report.composite_disagreements`.
  - CLI: `bigmont CAND VERDICT [--backend auto|gpu|cpu] [--adapter SUBSTR] [--vk-backend SUBSTR] [--device N] [--retune] [--cache PATH] [--verify-rate N] [--repeat N] [--lock PATH]`; `--repeat` and `--lock` are accepted and ignored with a one-line note; `--inject`, `--ee`, `--bins`, `--chunk`, `--growth`, `--marker` exit with code 2 and the message `bigmont: <flag> is not supported yet`. Subcommand `bigmont canary CAND EXPECTED [same engine flags]` runs the engine over `CAND` and exits 0 only if every verdict equals the corresponding byte of the `G2V1` file `EXPECTED` (exit 1 and the first ten mismatching indices otherwise). Subcommand `bigmont tune [--bits N]` prints the autotune table for that size (default 2029). Exit code 2 for usage and I/O errors. Prints a summary to stderr: backend and adapter, tests, seconds, tests/s, PRP count, disagreement counters.
