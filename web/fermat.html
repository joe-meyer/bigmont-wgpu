bigmont WebGPU Fermat-ladder test

Compiles generated Fermat-ladder kernels (kernels/matrix/NAME.wgsl, written by dump_wgsl) in this browser's own WebGPU implementation, runs the base-2 Fermat test on a mixed batch on the GPU and checks every verdict against a BigInt 2^(n-1) mod n == 1 oracle. Query: ?k=fermat_b2029_tpi8_wg64,fermat_b254_tpi4_wg64 (comma separated), &compile=1 compiles only, &count=4096 sets the throughput batch (0 skips it). Names starting limb32_ are the native-only 32-bit kernels: they are EXPECTED to be rejected here (negative control).
