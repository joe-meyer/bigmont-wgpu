bigmont Rust engine on WebGPU

Runs the Rust Fermat runner (bigmont-core, compiled to wasm by bigmont-wasm) on this browser's WebGPU and checks every verdict against a BigInt 2^(n-1) mod n == 1 oracle. Needs web/pkg/, built as described in README.md. Query: ?bits=255,1019,2029, &tpi=8, &wg=64, &count=24 (candidates per size), &gec=1 (run with the Gerbicz error check: every verdict must still equal the oracle and no candidate may raise an alarm). Results are also in window.__rust.
